# Base-de-IA-da-Taranis-Black-by-EJM
A TB é nacional de ergonomia corporativa. Ela vende cadeiras de alto desempenho, mesas elétricas e cabines acústicas para escritórios. Fatura R$48 milhões/ano, 280 colaboradores e cresceu 35% ao ano nos ult. 3 anos. Isso tem um custo: os processos permaneceram manuais e burocráticos, e a empresa está começando a perder eficiência.
